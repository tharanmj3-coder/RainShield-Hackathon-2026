# 🌧️ RAINSHIELD
## Intelligent Rain-Responsive Bus Window System

### 🚍 Project Overview

RAINSHIELD is an intelligent vehicle safety and comfort system designed to automatically respond to rainfall and protect passengers from sudden weather conditions.

The system detects rainfall using a rain sensor and automatically controls a passenger window using an SG90 servo motor.

A live automotive-style HMI dashboard provides real-time monitoring of the vehicle system.

---

## 🎯 Problem Statement

During sudden rainfall, passengers may not have enough time to manually close vehicle windows.

RAINSHIELD provides an automatic response by detecting rainfall and controlling the vehicle window without requiring manual intervention.
